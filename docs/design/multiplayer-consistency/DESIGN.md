# Persistent multiplayer standings refinement

The user now prefers standings floating on the right, revising the earlier choice to place them below the full-width stage. This is a focused component/layout refinement; preserve solo controls, theme, audio, search, Noot continuity and server-owned scores.

Options carried forward from the existing study: below-stage grid (clean but easy to miss), a top standings strip (displaces listening controls), and a right-side rail (keeps competition visible). Select the user-requested right rail: a 300px sticky panel, separated by space and a restrained raised surface, not an overlay on the play/search area. On narrow screens, use a persistent bottom-right standings disclosure with your rank/score. Open to a bounded scrolling list; no modal backdrop or playback interruption. Full names and scores support 2–12 players.

Motion contract: server scores change → stable player rows move to their new ranks → a short score/rank message explains who passed whom. Before: ranks and numbers at rest. Moving: rows interpolate from their current visible positions for about 500ms while existing ScoreNumber counts to the committed value. Settled: exact authoritative ranking; brief notice clears after five seconds. Rapid updates retarget from the in-flight position, cancel old animations, and keep latest scores authoritative. New matches/initial snapshots do not announce an overtake. Ties and new arrivals are not false overtakes. Keyboard and touch can open/close the narrow disclosure; Escape closes and restores toggle focus. Reduced motion settles geometry and scores immediately but retains textual feedback. WAAPI owns row transforms; CSS owns panel entry; existing ScoreNumber owns numeric presentation.

Pending evidence: desktop/narrow composition, actual intermediate/settled/reversed reorder, live reduced motion, 12-player scroll, reconnect/initial snapshot, keyboard disclosure, production build and focused rule tests. This is an agent design judgment; user acceptance remains pending.

## Requested collapsible standings redesign — September 8

New user feedback rejects the large rounded standings card and requests hide/show through an icon. This supersedes the previous permanently open desktop rail. Preserve right-side placement, authoritative scores/ties, row reordering, player interactions, overtake announcements, focus recovery and audio. Scope is MatchScoreboard/MatchStandings and their styles; do not alter the concurrently edited match logic.

Observed: the screenshot and local preview repeat your score twice, repeat Listening below every name, and devote 76px to each row. Desktop has no functioning disclosure; mobile already has one. Reference studies: Otherkind's aligned name/year engagement list (https://otherkind.design/) suggests aligned text can group ordinary rows without a card per row. This is a compositional inference, not evidence that an agency page solves game standings. WAI disclosure guidance (https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/) supplies the button + aria-expanded + controlled-content contract. Existing Lucide trophy and chevron symbols and Open Runde/Instrument Serif remain the asset/type system.

Three same-content arrangements, to prototype before product edits:
A. A right-side ledger: title/count and collapse icon, rank/name/score columns, small meaningful statuses. Closed = 44px trophy icon; desktop game uses freed rail width. Narrow = bounded floating ledger above the same bottom-right icon. Strong score comparison and existing placement; less permanently enclosed on desktop.
B. Horizontal score strip: three score/name columns under one header and toggle. Uses little height for 2–3 players, but needs wrapping and disrupts the existing right rail at 12 players.
C. Popover with own rank/score summary above a compact rival list and icon at the foot. Keeps self score distinct; divides comparison between two areas and repeats the same information when including full standings.
Provisional A. Shared content: You 12,500, Milo 12,000, Luna 8,500; additional stress = 12 players, tied leaders, 24-character names, six-digit totals, reconnect, revealed deltas, spectator. 8px base/4px half step; stable rank/name/score columns; 44px buttons; rows 52px minimum. No static motivational subtitle or duplicate total footer. Baseline Listening is omitted; changed attempt, solved, ready and reconnect states stay. Personal row identified by text and a small accent, not a full tinted card.

Interaction: initial desktop open, phone closed, explicit toggle works at every width. Collapsing leaves only the trophy button with accessible Show standings label. Reopening restores current scores without stale rank animation; remember choice in this session if storage works, in memory otherwise. Escape returns toggle focus, outside dismisses floating narrow panel only. Overtakes remain announced while closed and never force the panel open. No new modal/backdrop or playback change. Motion: stable icon hit area; immediate disclosure, restrained content fade only if it does not move the target; reduced motion immediate. Keep existing score/row motion authoritative. Review pending; no independent reviewers/subagents are available in this side conversation.

Prototype decision: A selected after A/B/C and reversed C/B/A renders. B makes score comparisons span horizontal columns and would fragment 12-player reading; C spends disproportionate space on your total. A keeps the same reading order for every participant and reduces the original roughly 390px card to about 220px for three baseline rows. Wireframe, type and surface were authored and inspected sequentially at /tmp/noot-board-study; the first wireframe capture exposed missing UTF-8 metadata, repaired before type review. The generated type lab confirmed Open Runde loaded and fits actual names/numerals; preserve it rather than add a new sans. The existing Instrument Serif at 26px gives the small standings title the game's heading voice. Narrow prototype confirms A's single column is readable at 390px. Fresh-context screening is unavailable here; these are self-review observations, not user acceptance. Product build now follows A, with a persistent 44px trophy toggle and no decorative icon morph because the same trophy continues to represent standings in both states.

### Collapsible ledger review

Implemented locally in MatchScoreboard, MatchStandings and isolated scoreboard.css; existing match/scoring/audio code preserved. Session visibility survives reload and round changes. Closed contents are removed from the accessibility tree; the retained trophy button describes your current rank/score. Overtake messages have a separate polite live region so hidden standings do not lose announcements. Opening remounts only the list, avoiding stale rank-position animations after hidden score updates. Desktop outside clicks keep the rail open; mobile outside clicks close the floating panel. No morph or disclosure entrance animation was added, so the button stays directly responsive with reduced motion as well.

Two observed surface repairs: the older stylesheet's personal-row tint won the initial cascade, corrected with an explicitly scoped personal-row rule; the initial long-list desktop height ran below the viewport, reduced to the existing 250px viewport allowance. Final ordinary three-player list is roughly 220px tall and uses a quiet rule, one heading, aligned scores, and no duplicate total or Listening subtitle. Mobile alone gets an enclosed raised surface because it overlays content.
